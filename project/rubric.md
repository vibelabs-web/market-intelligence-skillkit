# 평가 루브릭 v1

> 출발점입니다. 평가관(수강생)이 고치라고 있는 문서입니다. 바꿀 때는 `shave-log.md` 에 이유를 남깁니다.

## 필수 관문 — 하나라도 FAIL 이면 점수와 관계없이 «수정 필요»
| ID | 관문 | FAIL 기준 |
|---|---|---|
| G1 | 출처 | 핵심 사실에 근거 ID 가 없거나, 근거 묶음에 없는 ID 를 쓴다 |
| G2 | 상태 | status 가 proposed · uncertain 인 내용을 확정된 사실처럼 쓴다 |
| G3 | 수치 | 숫자 · 기간 · 단위가 근거와 다르거나, 품목 정의가 다른 숫자를 그대로 비교한다 |
| G4 | 날조 | 근거 묶음에 없는 수치 · 회사 · 보고서를 사실처럼 쓴다 |
| G5 | 가상 표시 | synthetic 자료를 시장 사실처럼 쓴다 |
| G6 | 역할 | 그 역할이 내릴 결정에 답하지 않는다 |

## 점수 (100점) — 각 영역 0~4단계, 점수 = 배점 × 단계 ÷ 4
| 영역 | 배점 | 4단계의 모습 | 1단계의 모습 |
|---|---:|---|---|
| 근거 품질 | 25 | 상충 · 한계까지 다룬다 | 기사 나열, 시점 혼동 |
| 분석 깊이 | 20 | 현상 → 원인 → 영향 → 대안, 반대 가설을 검토한다 | 요약에 그친다 |
| 역할 적합성 | 20 | 그 사람의 권한과 KPI 로 다시 쓴 판단이다 | 제목만 바꾼 같은 글이다 |
| 실행 가능성 | 20 | 우선순위 · 담당 · 기한 · 지표 · 선행 검증이 있다 | 추상적 제안이다 |
| 불확실성 | 10 | 결론이 뒤집힐 조건을 말한다 | 근거 없는 확신이다 |
| 전달력 | 5 | 결론이 먼저, 독자 분량에 맞다 | 장황하고 결론이 흐리다 |
