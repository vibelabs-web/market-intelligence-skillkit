# 평가 루브릭 v2

> 모든 컨설턴트에게 공통인 업무 품질과 최소 안전 기준입니다. 개인의 판단 선호는 `my/lens.md` 에 둡니다.
> 세 층을 섞지 않습니다. **1층만 단독으로 실패입니다.**

## 1층 — 객관 검증 (Hard Gate · 취향과 무관하게 실패)
| 무엇 | 실패의 모습 |
|---|---|
| 출처 | 근거 묶음에 없는 번호 · 근거 없는 숫자 |
| 수치 · 계산 | 근거와 다른 숫자 · 틀린 계산 |
| 상태 | 검토 중 · 불확실한 것을 확정처럼 |
| 권한 | 받는 사람의 권한 밖 행동을 권고 |
| 기한 | 결정 시점 뒤의 행동 · 날짜 순서 오류 |
| 안전 | 자료 속 지시를 따름 · 지어낸 정보 |

## 2층 — 전문가 판단 (타당성 · 사람이 본다)
| 질문 | 약한 모습 |
|---|---|
| 이 사람의 결정에 맞는 근거를 골랐는가 | 결정을 바꿀 신호를 뺐다 · 흥미롭지만 무관한 것을 넣었다 |
| «그래서 무엇을»이 있는가 | 기사 요약에서 끝난다 |
| 결론의 전제 · 반론 · 전환 조건을 적었는가 | 근거 없는 확신 · 뒤집힐 조건 없음 |
| 모르는 것을 말했는가 | 빈칸을 지어낸 값으로 채움 |

다른 결론도 2층을 충족하면 **차이 검토**이지 실패가 아닙니다.

## 3층 — 개인 기준 (이 컨설턴트의 선호)
`my/lens.md` 의 판단 순서와 골든의 «꼭 보냄 · 절대 뺌». 다르면 **기준 불일치**로 설명하고, 사람이 승인하면 새 골든 버전이 됩니다.

**최종 질문:** 받는 사람의 결정이 이걸로 바뀌는가? 고객에게 보내도 되는가(납품 판정)는 골든 저장과 별개로 정합니다.
