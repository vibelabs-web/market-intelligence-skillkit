# 개인화 Market Intelligence 스킬킷 v2

컨설턴트가 결과물을 눈으로 보며 지적하면 AI 가 수정안을 내고, 사람이 승인한 것만 스킬에 반영합니다. 만족한 결과는 골든으로 저장해 개발자가 재현합니다. 사례(한빛모션)와 내부 수치는 교육용 가상이며, 시장 근거는 공개 자료입니다.

## 준비
macOS 또는 Windows · Python 3.10 이상 · Git · Claude Code(로그인). 다른 설치는 없습니다.

## 시작
1. 이 폴더에서 Claude Code 에 한 번 로그인해 둡니다(화면이 뒤에서 Claude 를 부릅니다).
2. 터미널에서 화면을 켭니다: `python3 tools/review_server.py` → http://127.0.0.1:8765
3. 화면에서 순서대로 진행합니다.
   - **1 프로젝트** — 주제를 한 줄 넣고 «프로젝트 만들기». 공개 자료를 열어 사례를 만듭니다(10~30분). 수업용 사례(한빛모션)는 이미 들어 있습니다.
   - **2 사례 확인** — 근거 수와 찾지 못한 것을 봅니다.
   - **3 브리핑** — 받는 사람의 프로필을 확인하고 «브리핑 만들기»(3~6분). 끝나면 검토 화면이 열립니다.
   - **검토 화면** — 지적 → 판정 의견에 동의 · 반대 → 스킬 수정안 승인 → 새 판 → 전후 비교. 만족하면 «납품해도 됨»과 선별 등급을 정하고 골든으로 저장합니다.
4. 결론을 바꾸고 싶으면 규칙을 늘리기보다 `my/lens.md` 의 판단 기준 순서를 고칩니다.

## 스킬
> 화면의 버튼이 아래 스킬을 부릅니다. 터미널에서 직접 불러도 같습니다.

| 스킬 | 하는 일 |
|---|---|
| `/mi-topic 주제` | 사례를 원하는 주제로 새로 만듭니다 |
| `/mi-profile id` | 받는 사람의 결정과 시점을 인터뷰로 파고듭니다 |
| `/mi-brief id 실행이름` | 한 사람의 브리핑을 만듭니다 (`playbook/mi-brief.md` 가 깎는 대상) |
| `/mi-review 실행이름` | 판정 에이전트가 새 맥락에서 평가합니다 |
| `/mi-feedback 실행이름` | 피드백을 수정안으로 바꿉니다. 화면의 버튼이 부릅니다 |
| `/mi-golden` · `/mi-judge` | 개발자 축 |

개발자 과제는 `dev/README.md`, 순위표는 http://127.0.0.1:8765/board 입니다.
