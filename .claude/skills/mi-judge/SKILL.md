# 현재 골든과의 일치도 측정

## 절차
1. `python3 tools/golden_compare.py golden/<이름> <결과 폴더> [...]` 를 돌린다. 서로 다른 3회 결과를 넣으면 안정성까지 나온다.
2. `llm` 항목은 새 컨텍스트에서 결과별로 판정해 `<결과 폴더>/llm-judgments.csv`(`id,verdict`)로 저장한 뒤 다시 돌린다.
3. 결과의 `status` 별로 나눠 보고한다.
   - **FAIL: 객관 오류** — 근거 없는 숫자 · 계산 · 상태 단정 · 권한 · 자료 속 지시. 에이전트 버그다.
   - **기준 불일치** — 골든의 «꼭 보냄 · 절대 뺌»과 다름. 이 컨설턴트의 선별 선호를 못 따른 것.
   - **차이 검토** — 결론 · 판단 항목이 다름. 근거 · 전제 · 반론 · 판단 순서를 골든과 나란히 놓고 사람에게 넘긴다.
   - **일치**
4. 점수는 «현재 골든과의 일치도»라고 부른다. 정답률이라고 하지 않는다.

## 규칙
골든을 고치지 않는다. 골든 버전이 바뀌었으면 어느 버전 기준인지 밝히고, 이전 버전과의 단순 불일치를 «퇴보»로 단정하지 않는다. 다른 컨설턴트의 골든끼리 점수 순위를 매기지 않는다.
