# 근거 점검

## 입력
`project/brief.md` · `project/fact-pack/evidence-register.csv` · `my/lens.md`. 없으면 어떤 파일이 없는지 말하고 멈춘다.

## 절차
1. 브리프의 «이번에 정할 것»을 질문 3~5개로 나눈다.
2. 질문마다 근거를 묶고, 답할 근거가 모자란 질문은 **공백**으로 표시한다.
3. 비교 금지 쌍을 찾는다 — 품목 · 기간 · 통화 · 기준이 다른 숫자, `conflict_with` 가 있는 행. 왜 다른지 쓰고 평균 내거나 하나를 고르지 않는다.
4. status 와 낡음을 옮긴다. proposed · uncertain 은 확정 표현을 쓰지 않는다.
5. 추가 질문이 있고 웹 도구가 있으면 찾는다. 실제로 연 페이지만 `quote` 와 함께 새 행으로 넣는다. 열지 못하면 공백으로 남긴다.

## 출력
`runs/<run-id>/fact-base.md` — 질문별 사실(근거 ID) · 비교 금지 쌍 · 공백.

## 완료 조건
- 모든 사실 문장 끝에 `[E-xxx]` 가 있다.
- 숫자는 근거의 quote 에 있는 값 그대로다.
- 공백을 추측으로 메우지 않았다.

## 실패하면
근거가 없어 질문 절반 이상이 공백이면 분석으로 넘어가지 말고 어떤 자료가 필요한지 보고한다.

## 권한
시장 사실은 근거 묶음에서만 가져온다. 파일 쓰기는 `runs/` 와, 사용자가 승인한 근거 행 추가만.
